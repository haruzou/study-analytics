Built for how studying actually happens

Six focused views instead of one crowded dashboard — each one answers a single question about your study time.

Live focus sessions

Start a session and watch it log itself — deep work blocks, short reviews, and breaks are told apart automatically.

Subject breakdown

See where your hours actually go across courses, not where you meant them to go — updated after every session.

Streak tracking

Consistency without guilt-based badges — a streak counts a real day of study, not a login, and forgives one skipped day a week.

Weekly reports

A short written summary lands every Sunday — what shifted, what slipped, and one thing worth adjusting next week.

Goal pacing

Set an exam date and a target hour count. The dashboard shows whether your current pace actually gets you there in time.

Open data export

Every session is yours — pull the raw data as CSV or JSON at any time and take it wherever you need it.

Drop it into a GitHub Pages repo in a few minutes

This page is static and self-contained — clone it, point it at your own data source, and publish. No server to run, no framework lock-in.

  • Works as a standalone landing page or the index of a larger repo
  • No build step required — plain HTML, CSS, and a little JS
  • Swap the sample chart data for your own session export
